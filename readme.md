# Crear la carpeta del proyecto

mkdir landing-git

# Entrar a la carpeta

cd landing-git
Crear dentro de esa carpeta los archivos:
index.html
styles.css
Luego inicializar Git:

# Inicializar un repositorio Git en la carpeta actual

git init

# Consultar el estado del repositorio

git status
Agregar los archivos al área de preparación:

# Agregar todos los archivos al staging area

git add .

se adiere al area de preparacion al area de trabajo 
Crear el primer commit:

# Registrar la primera versión del proyecto

git commit git st
Verificar el historial:

# Ver el historial resumido

git log --oneline
